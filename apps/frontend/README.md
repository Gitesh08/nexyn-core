# Nexyn Core - Frontend

This is the Next.js visual dashboard for Nexyn Core. It allows you to inject raw data, observe the biological evaluation pipeline in real-time, and watch memories naturally decay and prune themselves.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

*Note: You must have the FastAPI backend running simultaneously on port 8000 for the dashboard to function correctly.*
